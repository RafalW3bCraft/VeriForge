# VeriForge User Guide

## First investigation

1. Open **New investigation**.
2. Select message, email, or URL and paste only the material required for review. Never paste passwords, tokens, or unrelated private data.
3. Review the evidence-backed verdict, confidence, evidence strength, recommendations, and any incomplete-investigation warning.
4. Use the evidence table for an accessible source list, the relationship view for context, and JSON download or print for a case record.

The supplied practice samples are synthetic. An investigation is decision support, not proof of compromise or a substitute for incident-response procedures.

## Reading a result

- **Verdict** is a deterministic risk decision constrained by verified evidence.
- **Confidence** describes the verifier’s certainty; **evidence strength** describes traceable source support. They are not interchangeable.
- **Unsupported claims**, contradictions, and missing corroboration remain visible and cannot be treated as confirmed findings.
- **Incomplete** means a required service, such as external enrichment, failed or was unavailable. It is not evidence that the input is safe.

## History and privacy

History shows only investigations permitted to the signed-in account. In local legacy mode, history remains a single-user workspace. In account mode, use an administrator-created account; viewers need an explicit investigation grant.
